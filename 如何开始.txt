【怎么开始玩】

方式 A（推荐）：双击「启动本地服务器.cmd」
  · 脚本会用 Python 起一个本地小服务器，并自动打开 http://localhost:8080
  · 这种方式下存档、变量、API 接入都最正常
  · 看到黑色窗口不要关，关掉就等于停止服务器

方式 B（最省事）：解压后双击 index.html
  · 必须先完整解压！不要在压缩包的预览窗口里直接点 index.html
  · 建议用 Chrome / Edge（不要用 IE）
  · 这种 file:// 方式下，浏览器的存档(localStorage)可能不稳定，
    换浏览器或清缓存都可能丢档，重要进度请用游戏内「存档清单 → 导出」备份

【玩之前要知道的】

1. 分辨率：1720×1000 效果最好，最低建议 1280 宽。这是桌面端界面，手机上体验不佳。
2. 字体：联网时会加载在线字体，离线自动回退到系统字体，不影响功能。
3. 存档：自动存档 1 个 + 手动 6 个，全部存在你自己的浏览器里。
   · 换电脑、换浏览器、清缓存 = 看不到旧档
   · 「查看档案 → 导出」可以把存档导出成 JSON 文本，自己留一份
4. AI 接入（可选）：安装后默认是「本地引擎」，不联网也能完整游玩。
   如果你想接真实大模型：进入酒馆模式 → 左侧「API 接入」→ 填 Base URL / Key / 模型。
   · 浏览器从本地文件直连第三方 API 常被 CORS 拦截，建议指向本地服务：
     LM Studio  http://127.0.0.1:1234/v1
     Ollama     http://127.0.0.1:11434/v1
     或自填一个代理前缀
   · Key 只保存在你自己的浏览器里，不会上传到任何地方

【常用快捷键】

  空格         继续推演 / 跳过打字动画
  1 - 9        选择对应编号的抉择
  V            切换「叙事模式 / 酒馆模式」
  D            选手档案        S  存档清单
  B            比赛直播        C  赛程日历
  T            日程规划        M  舆论平台
  Q            任务清单        A  成就殿堂
  N            世界快讯        H  操作指南
  X            作弊菜单（仅作弊模式存档可见）
  /            聚焦「自由行动」输入框
  Esc          关闭当前浮层

【酒馆模式是什么】

按 V 切换。它是仿 SillyTavern 的楼层式界面：
  · 你说话 → 主持回复成「楼层」，每层带思考折叠、正文、选项、变量变更
  · 每层都存了变量快照，可以「回滚到此楼」，也可以「分支」开一条新线
  · 左侧是世界书（46 支俱乐部 / 特工地图 / 人物档案 / 规则速查），命中关键词才注入上下文
  · 「上下文」按钮可以看到真实送进模型的提示词与 token 占用

【遇到问题】

· 白屏：换个浏览器（Chrome / Edge 最新版），或按 F12 看 Console 报错
· 存档没了：清缓存或换浏览器导致，无法找回；下次记得导出存档
· 找不到自己想要的玩法：直接在下方的「自由行动」输入框里写你想做的事，
  例如「加练三小时靶场」「约队友去吃火锅」「开直播回应质疑」
